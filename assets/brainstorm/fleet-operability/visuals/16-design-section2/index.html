Design §2 — Matrix runner (selftest --matrix)

Architecture of the truth gate. Approve in terminal to continue.

Command surface

synlynk selftest --matrix              # dry (default): no model $, CI-safe
synlynk selftest --matrix --live       # live tiers; budget-capped
synlynk selftest --matrix --live --budget 10   # default $10/week enforced

Grid

  • Homes (rows): claude, agy, codex, grok (not local)
  • Verb columns: status, doctor, dispatch-dry, jobs, logs, pr-check (dry), cost (schema), story (list)
  • Target columns (live only): dispatch trivial task to each of Core 4 as headless worker

Tiers

  1. Dry/contract — argv matches baseline; instruction file exists; doctor TC-2/3; no nested state.db; free
  2. Live trivial — real agent call, minimal prompt, assert exit 0 + reconciled terminal status + cost row (or explicit zero)
  3. Live git-only — optional later; worktree commit smoke (not Phase 1)
  4. Live GH-write — only after GH-write epic; only agents with can_gh_write proven

Phase 1 ships tier 1. Phase 2 ships tier 2 under $10/week hard stop (abort remaining cells; mark incomplete not green).

Storage

Results → state.db table fleet_matrix_runs (run_id, tier, home, cell, status, detail, ts, cost_usd). Last green timestamps drive Proven freshness in synlynk status.

Assertions (any failure = cell red)

  • Exit 0 and job terminal status ≠ UNKNOWN
  • Instruction file present for agent under test
  • No nested product state.db under worktrees/
  • Live: cost ledger entry or explicit zero-cost marker
  • Codex builder-only: GH-write cells are N/A (not red) until epic lifts the label
