# Task-oriented how-tos

Choose a recipe by outcome:

- [Initialize a repository](initialize.md) — set up shared context and inspect what was created.
- [Dispatch a task](dispatch-a-task.md) — give Synlynk a bounded task with useful verification criteria.
- [Inspect and review results](inspect-results.md) — follow a job from dispatch through review.

These recipes explain the common workflow; the [command reference](../reference/commands.md)
covers the full surface, including advanced and administrative commands.
