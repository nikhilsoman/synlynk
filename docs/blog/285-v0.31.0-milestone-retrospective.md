## Overview

Synlynk `v0.31.0` delivers the architectural foundation for **Horizon 3: Autonomous Fleet Governance & Universal Archetypes**. This release decouples agent roles from software-specific titles into 6 universal capability-neutral archetypes, enables multi-discipline 1:N cardinality and secondary hats across diverse industries (e.g. film production pipelines in Hitchcock, clinical trials in Rxcc), introduces a 3-tier evolutionary autonomy ladder with automatic Sentinel demotions, and integrates an offline-first Visual Organogram Canvas in Vizor.

## What Shipped in v0.31.0

### 1. Six Universal Capability-Neutral Archetypes
- **Universal Taxonomies:** Introduced `orchestrator`, `strategist`, `director`, `creator`, `inspector`, and `custodian`.
- **Capability-Neutral Core:** Abstracted all software-specific lifecycle mechanics (TDD, worktrees, git merges) out of core archetype definitions into modular domain packs.
- **1:N Cardinality & Secondary Hats:** Enabled multiple agents to instantiate the same archetype across specialized disciplines (e.g. `creator` as editor, animator, sound-designer) and wear secondary hats (e.g. `creator` with `inspector` hat).
- **SQLite Schema Migration:** Added `agent_archetypes`, `agent_workflow_edges`, and `rsi_evaluations` tables with backwards-compatible schema extensions to `workspace_agents`.

### 2. In-Repo Domain Profile Packs & Confirmation Boundaries
- **Versioned Domain Profiles:** Shipped in-repo packs for `software.json`, `hitchcock.json` (film studio), and `rxcc.json` (clinical trials).
- **Taxonomy Security Boundary:** Enforced that taxonomy suggestions (SFIA/APQC) serve strictly as advisory baselines (`requires_confirmation=True`), preventing automatic tool grants or filesystem write access without explicit human sign-off.
- **Mandatory Domain Caps:** Hard-coded autonomy ceilings for regulated domains (e.g. `Rxcc` capped at $\le$ `L2_GATED`).

### 3. Three-Tier Autonomy Evolutionary Ladder
- **Autonomy Progression:** `L1_ADVISORY` (observe & propose) $\to$ `L2_GATED` (supervised approval) $\to$ `L3_AUTONOMOUS` (unattended execution).
- **Human-Only Promotion:** Safety invariant requiring explicit human authorization (`authorized_by="human"`) — agent self-promotion fails closed.
- **Automatic Sentinel Demotion:** Integrated automatic demotion hooks into the token circuit breaker (`TOKEN_CIRCUIT_BREAKER_TRIPPED`), recording immutable incident audit receipts in `rsi_evaluations`.
- **Launch Constraints:** L3 execution restricted strictly to the reference `@tpm` orchestrator at launch.

### 4. Interactive Visual Organogram Canvas in Vizor
- **Offline-First Tree Projection:** Built SVG/HTML5 interactive organogram canvas at `/w/<slug>/organogram.html` with zero external CDN dependencies.
- **HUD & Inspection Drawer:** Visualized reporting edges, secondary hat chips, autonomy badges, and collapsible details drawers.

### 5. CLI & Governance Surface
- **Autonomy CLI Verb:** Added `synlynk autonomy {status,promote,demote}` registered under Tier 2 sustain commands.
- **Documentation Synchronization:** Updated command references and official documentation bundles.
