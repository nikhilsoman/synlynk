# Research: SCIP Indexers

This document summarizes the current state of research into SCIP (Source Code Indexing Protocol) indexers, their design, and how they can be integrated into Synlynk for code intelligence.

## Overview
- SCIP is a language-agnostic protocol for providing code navigation, symbol lookup, and cross-referencing.
- Indexers ingest source files and produce a searchable index that can be queried by IDEs and language servers.
- Key features include fast incremental updates, support for large codebases, and interoperability with tools like Tree‑sitter.

## Relevant Projects
- **Scip** (https://github.com/sourcegraph/scip) – reference implementation in Go.
- **Glean** – internal Google code‑search infrastructure that consumes SCIP indexes.

## Integration Points for Synlynk
1. **Parsing** – Use Tree‑sitter to generate syntax trees for source files.
2. **Symbol Extraction** – Walk the Tree‑sitter AST to collect symbols, definitions, and references.
3. **Index Generation** – Serialize symbols into the SCIP protobuf format.
4. **Query API** – Provide a Python wrapper around the SCIP index for lookup.

## Open Questions
