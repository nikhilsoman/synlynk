# Research: Tree-sitter Symbol Graphs

Tree‑sitter provides incremental parsing and concrete syntax trees for many languages. Symbol graphs can be derived by walking these trees and extracting definitions, references, and relationships.

## Key Concepts
- **Node Types** – Each language grammar defines node types (e.g., `function_definition`, `class_declaration`).
- **Queries** – Tree‑sitter query language allows pattern matching on the syntax tree to locate symbols.
- **Incrementality** – The parser can re‑parse only edited regions, enabling fast updates to the symbol graph.

## Integration Steps for Synlynk
1. **Parse Files** – Use `tree_sitter` Python bindings to parse source files.
2. **Define Queries** – Write language‑specific queries to capture symbols and their scopes.
3. **Build Graph** – Construct a directed graph where nodes are symbols and edges represent definitions, references, and inheritance.
4. **Export** – Serialize the graph in a format consumable by SCIP or Glean (e.g., protobuf or JSON).

## Benefits
- Language‑agnostic source analysis.
- Near‑real‑time updates as developers edit code.
- Foundation for richer code‑intelligence features such as go‑to‑definition, find‑references, and call graphs.
