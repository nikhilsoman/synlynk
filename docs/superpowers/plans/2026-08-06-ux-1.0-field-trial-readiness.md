# UX 1.0 Field Trial Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **Per this repo's CLAUDE.md, all implementation/testing dispatches must route through `synlynk dispatch <agent> --force-agent --context-mode full` to Codex/Grok/Agy — Claude does not implement code; Phase 1 (Task 1) is PM/verification work and stays with Claude.**

**Goal:** Validate the 3 shipped UX 1.0 surfaces against real workflows, ship a journey-map documentation artifact, wire UX-1.0-specific in-context nudges into the shared terminal-tip/Vizor-banner/Slack-link mechanisms, and gate a field trial before the next Named Release.

**Architecture:** Four independently-dispatchable work packages. Phase 1 is a manually-run PM checklist (no code). Phase 2 is a static single-file HTML artifact under `docs/brainstorm/ux-journey-map/`. Phase 3a plugs a UX-1.0 tip producer into the terminal-tip mechanism built by `docs/superpowers/plans/2026-08-08-governs-lifecycle-workspace-agent-pilot.md` (`synlynk/fencing.py`'s `NudgeData`/`render_nudge_fence`, `.synlynk/config.json`'s `nudges` block); 3b injects a first-visit banner into Vizor's generated static HTML (`generate_index_html` in `synlynk/viz.py`); 3c extends the Slack notifier payload (`synlynk/notifiers/slack.py`). Phase 4 is a gate checklist, not code.

**Tech Stack:** Python 3 stdlib, pytest, existing synlynk CLI/HTTP conventions, plain HTML/CSS/JS (Tailwind CDN) for the journey-map artifact.

**Plan-time correction from the spec's literal text:** Section "Phase 3" line 86 of the spec says the `nudges` config block lives in `~/.synlynk/config.json`. Per the GOVERNS plan's Task 6 (already flagging the same correction against its own source spec), this codebase has no global config file anywhere — `load_config()`/`_update_config()` and all ~10 other call sites use the project-local `.synlynk/config.json` exclusively. ```python
"""UX-1.0-specific tip producer, plugged into the shared terminal-tip mechanism
built by docs/superpowers/plans/2026-08-08-governs-lifecycle-workspace-agent-pilot.md
(synlynk/fencing.py's NudgeData/render_nudge_fence, .synlynk/config.json's nudges block).

This module owns only the UX-1.0 heuristic (which underused surface to suggest);
it does not own presentation or config persistence — those live in fencing.py
and synlynk/__init__.py's load_config()/_update_config(), already built.
"""

TUI_TIP_ID = "ux-tip-tui-watch-live"


def pending_ux_tip():
    """Returns a NudgeData for an underused surface, or None if nothing to show.

    Heuristic (v1, deliberately simple per YAGNI): if 2+ jobs are currently
    'running' in daemon_jobs, suggest `synlynk tui` to watch them live. Does
    not track per-tip 'last_shown' frequency beyond config's dismissed_ids
    suppression — a richer novelty heuristic is not required by the spec's
    Phase 3a scope and can be added later without changing this function's
    signature.
    """
    from synlynk import _get_db, load_config
    from synlynk.fencing import NudgeData

    config = load_config()
    nudges_cfg = config.get("nudges", {"enabled": True, "dismissed_ids": [], "last_shown": {}})
    if not nudges_cfg.get("enabled", True):
        return None
    if TUI_TIP_ID in nudges_cfg.get("dismissed_ids", []):
        return None

    conn = _get_db()
    running_count = conn.execute(
        "SELECT COUNT(*) FROM daemon_jobs WHERE status='running'"
    ).fetchone()[0]
    conn.close()

    if running_count < 2:
        return None

    return NudgeData(
        nudge_id=TUI_TIP_ID,
        title="Underused surface",
        message=f"{running_count} jobs running — watch them live: synlynk tui",
        follow_up="synlynk tui",
    )
```

def _print_pending_nudges() -> None:
    """Prints any nudges the pilot workspace agent has queued, gated by config."""
    load_config_fn = _pkg("load_config")
    config = load_config_fn() if load_config_fn else {}
    if not config.get("nudges", {}).get("enabled", True):
        return
    try:
        from synlynk.workspace_agent import cmd_workspace_agent_run
        cmd_workspace_agent_run()
    except Exception:
        pass
    try:
        from synlynk.ux_nudges import pending_ux_tip
        from synlynk.fencing import render_nudge_fence
        tip = pending_ux_tip()
        if tip:
            print(render_nudge_fence(tip))
    except Exception:
        pass

def _compute_underused_feature_banner(data: dict) -> Optional[str]:
    """Returns a dismissible-banner message for an underused Vizor feature,
    or None if nothing to suggest. v1 heuristic: 10+ jobs dispatched but
    approve/kill never used.
    """
    jobs = data.get("jobs", [])
    if len(jobs) < 10:
        return None
    if data.get("approve_kill_used", False):
        return None
    return f"You've dispatched {len(jobs)} jobs but never used approve/kill — try it"
```
