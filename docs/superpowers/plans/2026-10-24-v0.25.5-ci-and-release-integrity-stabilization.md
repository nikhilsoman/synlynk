> **For agentic workers & conductor:** Implementation is executed via `synlynk dispatch` per the Capability-Based Task Allocation table, with cross-harness PR reviews per the Hardened PR Review Policy. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the five stabilization workstreams for daily release `v0.25.5`: selftest concurrency isolation (#2527/#2526), release-docs test-count decoupling (#2522), CI path scoping and matrix acceleration (#2529 & directive), sparse worktree cone verification (#2320/#2202), and calibration diff-base contamination (#2567).

### Task 1: Self-Test Scratch Workspace PID Isolation (#2527, #2526)

**Harness Assignment:** Codex
**Files:**
- Modify: `synlynk/selftest.py`
- Modify: `synlynk/doctor.py`
- Test: `tests/test_selftest_isolation.py`

**Interfaces:**
- `_workspace_dir(ctx)` in `synlynk/selftest.py` writes `.owner.json` containing `{"pid": int, "created_at": float}` into newly created `synlynk-selftest-*` scratch workspaces.
- `cleanup_selftest_workspaces(temp_root: str = None) -> int` in `synlynk/doctor.py` reads `.owner.json` and skips deletion if `os.kill(pid, 0)` succeeds, pruning only dead or stale (>1h) workspaces.

- [ ] **Step 1: Write the failing tests**
  Create `tests/test_selftest_isolation.py`:
  ```python
  import json
  import os
  import tempfile
  from synlynk.doctor import cleanup_selftest_workspaces

  def test_cleanup_preserves_active_process_workspace(tmp_path):
      active_dir = tmp_path / "synlynk-selftest-active"
      active_dir.mkdir()
      owner_file = active_dir / ".owner.json"
      owner_file.write_text(json.dumps({"pid": os.getpid(), "created_at": 1000000.0}))
      
      removed = cleanup_selftest_workspaces(temp_root=str(tmp_path))
      assert removed == 0
      assert active_dir.exists()

  def test_cleanup_removes_dead_process_workspace(tmp_path):
      dead_dir = tmp_path / "synlynk-selftest-dead"
      dead_dir.mkdir()
      owner_file = dead_dir / ".owner.json"
      # PID 99999999 is virtually guaranteed to not exist
      owner_file.write_text(json.dumps({"pid": 99999999, "created_at": 1000000.0}))
      
      removed = cleanup_selftest_workspaces(temp_root=str(tmp_path))
      assert removed == 1
      assert not dead_dir.exists()
  ```

- [ ] **Step 2: Run test to verify it fails**
  Run: `pytest tests/test_selftest_isolation.py -q`
  Expected: FAIL (`assert removed == 0` fails because active dir is deleted).

- [ ] **Step 3: Implement owner metadata and safe cleanup**
  - In `synlynk/selftest.py`: update `_workspace_dir()` to write `.owner.json` with current PID and timestamp when a scratch directory is created.
  - In `synlynk/doctor.py`: update `cleanup_selftest_workspaces()` to inspect `.owner.json`. If PID is alive (`os.kill(pid, 0)`), skip directory. If PID is dead, remove. If `.owner.json` is missing, only remove if older than 3600 seconds.

- [ ] **Step 4: Run tests to verify they pass**
  Run: `pytest tests/test_selftest_isolation.py tests/test_selftest.py -q`
  Expected: All PASS.
