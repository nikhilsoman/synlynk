## 1. Decision

v0.26.7 is the Vizor write-path edition. It does four committed things, then keeps a dive list for work discovered while the milestone is open:

1. **Sweep the shipped Vizor surface** and classify every view as live-write, write-stub, or read-only. Wire stubs that already have a handler in `synlynk/viz/server.py` through the machine-scoped daemon. New writes go through `authorize_local_request` into `state.db` (or a documented sidecar). GOVERNS stage edits are **locked by default**.
2. **Repair secondary and cross-view links** so chrome and iframe stay in sync, and so topology switchers stop 404ing (#4967).
3. **Make Gantt a Gantt:** GOVERNS stages are fixed-width columns; sub-tasks are rows; occupying cells show fill volume; names do not overflow (#4968).
4. **Keep a dive list** for the rest of Vizor (World, Product brainstorm files, Journeys, Settings/FTUE, Graphify inspect, Hub junk slugs, Logical detail-on-expand, sentinel HUD). Pick those up while the milestone is in flight; they do not all have to ship in the first implementation PR.

Vendoring Jantt is **Wave E**, after Wave B (row Gantt) is on `main`. A Jantt adapter consumes a GOVERNS-only JSON document and never `workspace_views.logical`.

## 4. Cross-view links (#4967)

### Bug

1. Topology switchers in `synlynk/viz/canvases.py` hardcode `href="/tube.html"` (and `/logical.html`, `/product.html`, `/infra.html`, `/world.html`, `/board.html`, **`/timeline.html`**). Those paths are not workspace-scoped. Live 404.
2. Overview / Activity / Tube use relative `href="gantt.html"`. The iframe navigates; parent `setView` never runs; crumbs and sidebar stay on Overview.
3. `/timeline.html` is not a view. The page is `gantt.html`.

### Fix

- One link helper: given slug + view id, produce `/w/<slug>/<view>.html` **and** a click handler that calls `parent.setView(viewId, src, cat, label)` when `window.parent !== window`. Fallback: full navigation to chrome `index.html` with `?view=`.
- Replace `/timeline.html` with Gantt everywhere.
- Do not use site-root `/tube.html`.
- Tests: for each cached HTML view, every in-app `href` that is not `https:` / `mailto:` / `target=_blank` GitHub resolves to HTTP 200 on the live daemon (or a documented 501 stub). Include the 404s above as regression fixtures.

Out of this ticket: Hub `job-*` cards, brainstorm file serving, Settings alerts.

## 5. Gantt layout (#4968)

### Bug

`renderDrill` / `renderTask` in `synlynk/viz/gantt.py`:

- Grid is `260px repeat(N, 1fr)` where **N is task count**.
- Task names become **column headers**.
- Each row is one absolutely positioned bar (`left: index/N`, `width: 0.85/N`) with `white-space:nowrap`, so labels overflow the cell.

Overview rows still use `start_frac` / `width_frac` as a stage strip across `repeat(10, 1fr)`. That is a stage ribbon, not a task Gantt.

### Fix

- **Columns** = GOVERNS stages of that release/milestone. **Fixed column width** (px, not `1fr` that collapses). Horizontal scroll if stages exceed the viewport.
- **Rows** = stories / sub-tasks (one row per task, name in the 260px label column, truncated with tooltip for the full id/title).
- **Cells** = fill volume for the stage that task occupies (done / active / queued / blocked). Fill is a bar *inside the cell*, not a label overflowing into the next stage. Empty stages for that task stay empty.
- Overview ribbon can stay as a collapsed summary; expanding a release shows the row Gantt, not the inverted task-as-column drill.
- Payload stays GOVERNS-only (`view_embed` keys already on Gantt). Do not re-embed `workspace_views.logical`.

Pencil notes and lock-by-default stage edits are write-path (section 6), not this layout ticket.

Jantt is **not** the layout fix. Jantt is a calendar CPM engine (`start`/`end` ISO, `dependsOn`). Wave E may replace or sit beside this grid once the row model exists.

## 6. Write-path sweep

### Policy

- Every POST goes through `authorize_local_request`. Fail closed.
- Daemon routes workspace-scoped writes under `/w/<slug>/…` **or** a documented global path that the iframe origin actually hits. Today's Gantt `fetch('/note')` hits `http://127.0.0.1:33333/note` and 404s; either proxy that path to `VizorHandler._handle_note_request` with workspace context, or change the client to `/w/<slug>/api/note`.
- GOVERNS stage/date edits: **locked by default**. Unlock is an explicit control. Commit is transactional `roadmap update` into canonical `state.db`. No silent local JSON as the source of truth for stages.
- Notes may keep `.synlynk/viz-notes.json` (`VIZ_NOTES_PATH`) if that remains the existing contract — document it. Do not invent a second notes store.
- Sentinel CTAs (#2672) stay **out of v0.26.6's read-only lock** until that issue's own write-path spec. This edition *hosts* that work; it does not silently turn the Overview panel into a writer.
- Personal GitHub tokens stay off-limits. Role App tokens only.

### Sweep method (implementation, after sign-off)

Walk every view in `_write_cache` plus chrome, Hub, onboarding. For each control (button, pencil, drag, href, `fetch`):

| Result | Action |
|---|---|
| Live write that already hits daemon | Keep; add a test |
| CTA that POSTs a `VizorHandler` path the daemon drops | Proxy or retarget |
| CTA that `alert()`s or 404s | Remove or replace with a real write in this edition / dive list |
| Pure read | Leave read |

Ship the classification table as a test fixture so a new stub cannot land without a row.
