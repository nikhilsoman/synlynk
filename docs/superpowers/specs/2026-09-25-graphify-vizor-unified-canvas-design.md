## 1. Executive Summary & Objectives

### 1.1 Problem Statement
1. **Manual & Disconnected Tooling:** While Graphify was integrated as a recommended ecosystem tool, it required manual invocation. `synlynk init`, `synlynk upgrade`, and `synlynk scan --deep` did not automatically provision or execute AST extractions, leaving new or updated workspaces without the `.synlynk/graphify-out/` knowledge graph substrate.
2. **Vizor Single-Repo Empty Canvas:** Vizor's `Architect Map` (`tube.html`) was originally built as a multi-repo ecosystem topology, rendering an isolated 1-box placeholder for single-repo workspaces (Monorepos).
3. **Static Fallback in Projections:** In `Logical View` (`logical.html`), Vizor rendered a basic SVG circle force-layout rather than embedding the rich, interactive Vis.js/D3 canvas generated by Graphify (featuring functional community clusters, node degree sizing, search filtering, and drawer inspection).

### 1.2 Core Objectives
- **Default Auto-Extraction:** Auto-provision `graphify` via `synlynk.tool_installer` if missing, and automatically run `graphify extract . --code-only --out .synlynk/graphify-out/` during `synlynk scan --deep` and `synlynk upgrade`.
- **Unified Clustered Canvas:**
  - **Monorepo Mode (`len(repos) == 1`):** Direct rendering of the repository's internal AST nodes, call chains, inheritance hierarchy, and functional community clusters with the interactive communities sidebar.
  - **Multi-Repo Mode (`len(repos) > 1`):** Unified clustered canvas rendering multiple bounded repository boxes with animated cross-repo API/contract bridges, smooth semantic zoom (LOD), and click-to-focus capabilities.
- **Zero Token Cost & Offline Guarantee:** All extractions run strictly in deterministic `--code-only` mode without LLM calls.

## 3. Data Pipeline & Automated Extraction Engine

### 3.1 Lifecycle Hooks
1. **`synlynk scan --deep`:**
   - In `synlynk/scan.py`, execute native directory skeleton scan and immediately trigger `_run_graphify_extract(repo_root)`.
   - If `graphify` binary is absent, invoke `synlynk.tool_installer.install_tool("graphify")`.
   - Run `graphify extract . --code-only --out .synlynk/graphify-out/`.
2. **`synlynk upgrade`:**
   - In `synlynk/upgrade.py`, run preflight health check for recommended tools and refresh the workspace graph cache.
3. **Multi-Repo Mesh (`synlynk mesh`):**
   - In `synlynk/mesh.py`, iterate through all member repos in `config.json`, load `.synlynk/graphify-out/graph.json` per repo, namespace nodes (`<repo_name>::<node_id>`), infer cross-repo HTTP/RPC routes, and write `.synlynk/graphify-out/federated-graph.json`.

## 4. Vizor Unified Clustered Canvas & UI Architecture

### 4.1 View Mapping & Route Integration
- **`TOPOLOGIES` → `Architect Map` (`tube.html`):**
  - For single repo: Directly hosts the interactive Vis.js graph (`graph.html`).
  - For multi repo: Renders the multi-cluster compound canvas with repository bounding boxes and cross-repo bridges.
- **`PROJECTIONS` → `Logical View` (`logical.html`):**
  - Renders intra-repo AST nodes, call hierarchies, and community cluster panels.
- **Direct Route Serving:**
  - `/w/<slug>/graphify.html` and `/w/<slug>/graph.html` served directly from `.synlynk/graphify-out/graph.html` by `synlynk/vizor_daemon.py`.

### 4.2 Interactive Canvas Capabilities
- **Communities Filter Panel:** Checkbox list of functional clusters (e.g. `APIRouter`, `SecurityBase`, `CLI`, `Daemon`) with color swatches and node counts.
- **Search & Highlighting:** Real-time search box highlighting matched nodes and focusing camera coordinates.
- **Node Drawer:** Clicking any node slides open the Vizor side drawer with:
  - Symbol kind (`function`, `class`, `module`, `endpoint`)
  - Source path and line number
  - Degree centrality ranking
  - "Dispatch agent to symbol" action button.
- **Theme Synchronization:** Dynamic CSS variable injection matching Vizor's `light`, `dark`, and `system` themes.

### 4.3 Commit Staleness Detection
- On render, compare `git rev-parse HEAD` against `manifest.json["built_at_commit"]`.
- If different, display an amber warning banner:
  ```text
  ⚠️ Graph Stale (differs from HEAD commit) — [Refresh Index]
  ```

## 5. Testing & Verification Strategy

1. **Auto-Installer Tests:** Verify `is_tool_available` and `install_tool("graphify")` across package managers (`uv`, `pipx`, `pip`).
2. **Scan & Extraction Tests:** Verify `synlynk scan --deep` outputs valid `.synlynk/graphify-out/graph.json` and `graph.html`.
3. **Vizor Rendering Tests:** Verify `tube.html`, `logical.html`, and `/w/<slug>/graphify.html` in `tests/test_viz.py`.
4. **Performance Benchmark:** Sub-second extraction and 60 FPS physics canvas for codebases up to 10,000 nodes.
