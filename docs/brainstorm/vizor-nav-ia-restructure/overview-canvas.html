What goes on the workspace overview canvas?

Shown the instant a workspace is selected, before any specific View is opened. Pick everything that should appear (multi-select) — this becomes the "root" breadcrumb page for that workspace.

1

Stat cards row

Active Goals, Open Stories, Jobs Running, Burn — quick-glance numbers pulled from synlynk status --json.

2

Recent/active jobs feed

Live-ish list of dispatched jobs for this workspace with status and PR links — the thing you currently check via synlynk jobs.

3

Jump-to-view shortcuts

One-click row/grid into each category's views, so the overview doubles as a launcher without needing the accordion still expanded.

4

Goal progress rollup

Mini progress bars per active GOVERNS goal (like synlynk goal status) — surfaces "what are we working toward" not just activity noise.

5

Alerts / sentinel banner

Surfaces active .synlynk/sentinel.md alerts (flatline, quota exhausted, etc.) right on the overview instead of only in CLI.
