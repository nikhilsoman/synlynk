## Executive answer

### Is full-fleet operability completely supported today?

**No.** Unanimous across all four panelists.

| Claim | Panel consensus | Notes |
|-------|-----------------|--------|
| **1. HOME** — use synlynk from inside any interactive harness CLI | **PARTIAL** everywhere | `synlynk open` works for claude/agy/codex/grok; **local missing from allowlist** while still listed as supported |
| **2. FUNCTION-100** — core verbs work fully (incl. sandboxed DB) | **PARTIAL** (codex: **FAIL**) | Verbs run on happy path; doctor false-greens; nested `state.db` still exists (#330); instruction reach unproven (#347) |
| **3. CROSS-DISPATCH** — home can reliably dispatch every peer headless | **Not for every target** | Best: claude. Weakest: **codex** (flag/auth/sandbox), **local** (not viable). Agy/Grok PARTIAL on side-effects |

**Biggest single gap (panel synthesis):** the system reports success (doctor green, job complete) **without verifying the underlying claim** — “completion theater” / false-greens. Every other open issue ultimately traces to the lack of a **live round-trip gate**.

## Top failure modes (pain-ranked, union of panel)

1. **Doctor / preflight false-greens** — flag presence ≠ working dispatch (#112, #332)
2. **Headless side-effects that can’t side-effect** — Agy/Codex GH-write (#426, #577); jobs “succeed” without PR actions
3. **Sandbox / nested state.db fragmentation** — #330 still visible under `worktrees/job-*/`; #648/#650 only softens crash
4. **Instruction fiction** — missing AGENTS.md, contaminated GROK.md, no load proof (#347, #344, #351, #345, #411)
5. **Vendor flag/version drift** — Codex `--approval-policy`; Grok `--yes` vs `--always-approve`; status version skew
6. **Completion theater** — UNKNOWN summaries (#579); attach 0%; green exit without cost/files/gh evidence
7. **local advertised but dead** — open exclude + TC-1/TC-3
8. **Grok CWD auto-relocation** — silent wrong cwd for costs/files (#342)

## Proposed empirical audit matrix (do this once and for all)

All four panelists independently proposed the same shape. This is the **gate before more fleet-parity stories**.

### Dimensions

| Axis | Values |
|------|--------|
| **Rows (home)** | claude, agy, codex, grok, (local only if still claimed) |
| **Cols (verbs)** | `status`, `doctor`, `dispatch --dry`, `dispatch` live trivial, `jobs`, `logs`, `pr check`, `cost`, `story`, `decide` |
| **Cols (targets)** | for each home: live dispatch → each fleet member |
| **Tiers** | (1) dry/contract (2) live no network write (3) live git-only worktree (4) live `--requires-gh-write` only on `can_gh_write` agents |

### Hard assertions per live cell (not optional)

- Exit 0 **and** job row terminal with real files/cost (or explicit zero)
- Instruction file present **and** hash/attestation (#347)
- Exactly one canonical `state.db` (fail on nested `.synlynk/state.db` under worktrees)
- Exact argv matches baseline (no silent flag drop)
- Auth + required network endpoints probed
- If GH-write claimed: evidence of `gh` side-effect or hard FAIL (not silent skip)

### Severity policy change to debate

- Doctor: **FAIL** (not warn) on missing AGENTS.md, nested state.db, TC-2/TC-3 hard fails, version skew vs running CLI
- Dispatch: block on failed preflight for target (#112)
- Status: hide or mark “unproven” empty capability cells instead of looking like coverage

## Brainstorm agenda (ordered)

Use this as the session outline. **Do not implement mid-brainstorm** — lock decisions first.

### Block 0 — Define “supported” (15 min)

1. What does **supported** mean?  
   - (a) CLI on PATH  
   - (b) doctor green  
   - (c) weekly green live matrix  
   - (d) something else  
2. Is “full fleet of five” a product claim or a marketing ceiling until proven?

**Decision needed:** one sentence definition of “supported,” enforced by CI/doctor.

### Block 1 — Live matrix gate (20 min)

3. Freeze new fleet-parity feature stories until the live audit matrix exists?  
4. Who owns the matrix runner — `selftest --live`, `doctor --matrix`, weekly cron job?  
5. Budget: max $ for weekly live matrix? Cap per cell?

**Decision needed:** gate yes/no; runner home; budget.

### Block 2 — Fleet membership (15 min)

6. **local (aider):** drop from advertised fleet until open + TC-1 + TC-3 green, or invest and pin?  
7. **codex:** treat as builder-only (no GH-write, no package-install claims) until TC-2/#577/#340 closed?  
8. Publish a **supported capability table** (home × headless × GH-write × network) that matches reality, not baselines?

**Decision needed:** fleet list for v0.13/v0.14 docs and dispatch help.

### Block 3 — Truth signals (20 min)

9. Doctor severity: promote which checks from warn → FAIL?  
10. Completion reporting: ban UNKNOWN as a terminal display; require reconciliation before “done”? (#579)  
11. Instruction truth: regenerate-only managed fences vs load attestation (#347)? Missing AGENTS.md = hard fail?  
12. Single canonical state.db: hard error on nested copies (#330)?

**Decision needed:** severity matrix + one state policy.

### Block 4 — Side-effects & identity (15 min)

13. GH-write forever “claude/grok only” vs close #426 with role-scoped tokens (#569 reality check)?  
14. Grants (#338): implement for all agents or remove from docs/UI until real?  
15. Preflight: fail-closed on missing auth/instructions (codex’s design principle) — yes/no?

**Decision needed:** GH-write routing policy + grants fate.

### Block 5 — Strategy go/no-go (20 min)

16. **Wrapper vs native harness** (`docs/strategy/synlynk-as-a-harness.md`):  
    - Keep patching vendor CLI parity indefinitely?  
    - Or freeze parity investment and schedule native loop for sandbox/grants/telemetry?  
17. Panel order was explicit: **matrix first → fleet list second → wrapper-vs-native third.** Confirm or reorder.

**Decision needed:** go / no-go / deferred-with-date on native harness; stop-the-line rules for wrapper patches.

### Block 6 — Near-term stop-the-line fixes (10 min, optional)

Only if Block 1–2 already decided. Candidates (not pre-ordered):

- Add AGENTS.md / fix TC-2 baseline for codex  
- Doctor FAIL on nested state.db + missing instruction
