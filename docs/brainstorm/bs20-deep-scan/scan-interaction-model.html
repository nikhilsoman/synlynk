B — Stage Cards (Recommended)

Each scan stage completes and reveals a summary card. User can press a key to expand any card for detail while remaining stages run in parallel. Interactive without blocking.

Best for: architect-grade review + quick navigation to what matters

C — Debrief Mode

Scan runs silently, then presents the top findings as ranked opportunities with one-key dispatch. Clean, opinionated, action-oriented — hides the process, shows the insight.

Best for: users who want answers not process
